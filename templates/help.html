Help & how-to

A short guide to using the HOA Task Manager. If something isn't covered here, check with whoever set up the app for your board.

Getting started

The first time you log in, set up two things on your Account page:

  1. Your timezone — so dates and activity timestamps display correctly.
  2. Your roster person link — connects your login to your name on the roster, so when you make changes the activity log shows your name (not your email address).

If you forget your password, use the "Forgot password?" link on the sign-in page — a reset link will be emailed to you. The link is good for 3 days.

Daily workflows

Create a new project

  1. Click + New project on the Projects page.
  2. Fill in title, category, and (optionally) priority, due date, vendor, and budget.
  3. Save. You can come back and edit any field individually from the project's detail page.

Assign people to a project (RACI)

On the project page, the RACI section has a form to add a person and a role (Responsible / Accountable / Consulted / Informed). You can add multiple people per project, including the same person in multiple roles.

If you've set up a group (see below), you can add an entire committee at once — pick the group instead of a single person.

Track progress with a checklist

The Checklist section on each project lets you break a project into steps. Add each step with an optional due date. Check items off as you complete them.

When you check the last item, the app asks if you want to mark the whole project as Completed. You can say "Not yet" if there's more to do.

Attach a vendor quote or photo

The Attachments section accepts PDFs, photos, and Office documents (up to 10 MB per file, 50 MB per project total). Files are stored securely off-site; only logged-in users can download them.

Leave a note

The Notes section is for context — "vendor came back with a new bid", "spoke to the painter, scheduled for Friday", and so on. Pin one note as the project summary so anyone reading the page can catch up in 30 seconds. Notes support basic Markdown formatting.

RACI explained

RACI is a way to be clear about who's involved in a project and how. For each project, each person can be:

Responsible (R):
The one doing the work. Every project should have at least one.
Accountable (A):
The one ultimately answerable for the outcome — usually the board officer who'll report on it.
Consulted (C):
Someone whose input is needed before decisions.
Informed (I):
Someone who just needs to know what's happening — no input expected.

A common pattern: the project's chair is Accountable, a board member or volunteer is Responsible, the relevant committee members are Consulted, and the rest of the board is Informed.

Groups & committees

Groups are named collections of people — typically committees like "Finance Committee" or "Architecture Review". Set them up under Roster → Groups.

When a group is on a project's RACI, the "via <Group>" annotation tells you how the assignment got there.

Important: changing a group's membership later does NOT automatically update projects the group was already added to. If you add a new committee member, go to each relevant project and click "Add group" again to bring them in. Existing members are skipped — the operation is idempotent, so only the new member gets a new row.

Views: Dashboard, Board, Calendar, Reports

Dashboard

The home page. Shows four headline numbers (Overdue, Upcoming 14 days, In progress, Done this month). Each is clickable — it'll take you to a filtered project list. The "Showing tasks for" dropdown narrows the whole dashboard to one person.

Board

A Kanban-style view: in-flight projects laid out as cards in columns by status. Drag a card from one column to another to change its status — activity log records the change automatically. The "Show completed" checkbox brings in a fourth column when you want to celebrate.

Calendar

Month view of due dates. Project pills are colored by status; checklist items show as outlined ☐ rows below the pills, with a left-border color that's shared across all items belonging to the same project (so you can visually trace which steps belong together). Click anything to open the project. Filter by person, category, and status.

Reports

Summary of completed projects over any date range. Use the preset buttons (This month, Last quarter, etc.) or pick custom dates. Shows headline numbers and a per-category breakdown — useful for talking points at board meetings.

Inviting board members

If you're a staff user, an "Invite user" link appears in the sidebar. Enter the invitee's email; they get an email with a link to set their own password. The link is good for 3 days. After they set their password, they can sign in.

Invitees see the full app, just like you. There's no per-person project-visibility separation — the design assumes everyone on the board can see everything (which is how an HOA board actually operates).

FAQ

My password reset link said "Link expired or invalid".

Try clicking it again. If that doesn't work, request a fresh link from the "Forgot password?" page. (Email-safety scanners occasionally pre-fetch links and can cause this on first click — rare, and the link itself isn't actually invalidated.)

I deleted a project by mistake.

Deletes are permanent in the app. The database is backed up daily, so restoring is possible but not self-serve — talk to whoever administers the app.

What's a "recurring template"?

A project marked as recurring (Monthly review, Quarterly audit, etc.) automatically spawns a fresh project instance on each cycle. The template itself doesn't show up on the board or calendar; the generated instances do. Manage templates under the Recurring page in the sidebar.

Can I export the data?

A CSV export is on the roadmap. For now, bulk-importing from CSV works via the Import projects page.

What's the small "via Finance Committee" annotation on a RACI row?

It means the assignment was added by expanding a group, rather than one-by-one. The annotation is for audit reference; the row works exactly the same as any other RACI assignment.
